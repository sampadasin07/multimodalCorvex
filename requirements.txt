# CORVEX — Root Python Requirements
# =============================================================================
# One shared virtual environment for both the FastAPI backend and the ML
# inference pipeline.  The backend imports the ML code directly in-process
# (see backend/app/predictor.py and backend/app/explainer.py), so all Python
# packages — web server and data science alike — must be installed together.
#
# Usage (from the repository root):
#   python -m venv .venv
#   .venv\Scripts\activate          # Windows
#   source .venv/bin/activate       # macOS / Linux
#   pip install -r requirements.txt
#
# Tested with Python 3.13 (.venv) and Python 3.10 (system).
# Minimum supported: Python 3.10.
# =============================================================================
